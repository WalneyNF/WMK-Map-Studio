Manual — v0.2.1

Instalação

Instale Node.js 22 ou superior, extraia o ZIP e execute INICIAR.bat. Abra a URL mostrada no terminal. Não abra index.html diretamente.

Primeiro projeto

  1. Clique em Novo projeto e altere o nome.
  2. Crie um mapa 2D de 32 × 24 tiles de 32 pixels.
  3. Selecione uma camada e um tile da paleta. Pinte arrastando com o botão esquerdo.
  4. Escolha a borracha para apagar. Scroll altera zoom; botão central move o mapa.
  5. Use os controles +, −, ↑, ↓ para administrar camadas. Duplo clique renomeia, o olho controla visibilidade e o cadeado bloqueia edição.
  6. Importe uma spritesheet PNG/WebP de até 1 MB após configurar tile, margem e espaçamento.
  7. Use Ctrl+Z e Ctrl+Y para testar o histórico.
  8. Salve com Ctrl+S e abra o JSON salvo.
  9. Abra exemplos/vila.project.json para editar uma vila pronta.
  10. Crie um mapa 3D: nesta versão somente os metadados estão disponíveis.
  11. Arraste o título de um painel para outra posição na grade, redimensione pelo canto inferior e feche pelo X. Reabra pelo menu Painéis.
  12. Altere um mapa e use Recuperar autosave após aparecer a mensagem de recuperação no console.

Arquitetura

projectFormat.js cria e valida dados; projectStore.js gerencia estado e histórico; persistence.js controla importação, exportação e autosave; workspace.js controla painéis; main.js conecta a interface ao núcleo; editors/2d contém renderização e operações de tiles.

O JSON usa schemaVersion 1. Não coloque código executável no mapa. Triggers e objetos ainda não possuem editor específico.

Limitações e testes

Execute npm test. A interface precisa ser validada no navegador. O autosave localStorage guarda uma cópia, não substitui o arquivo. Em navegadores sem seletor de gravação, o download não é confirmado automaticamente. Painéis usam uma grade e podem se sobrepor; restaure o layout se necessário. Spritesheets ficam incorporadas ao JSON nesta versão.
